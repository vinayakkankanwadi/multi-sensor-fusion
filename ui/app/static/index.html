Clock sync

SourceTime (UTC) / fixΔ vs referenceStatusDetail

Reference clock is the NTP server when reachable, otherwise the local container/host clock. Δ shows how far each source is from the reference. The Windows time is extracted from the SAPIENT RegistrationAck the harness sends back — no extra service required on the Windows side.

Endpoint

Endpoints + the validate flag are saved in your browser. NTP badge in the header turns yellow if local clock skew > 0.5 s, red above 2 s — the harness rejects skewed timestamps. TAK fan-out is handled by Apex (Parent forwardAll → cot-bridge → TAK), so the UI no longer needs its own TAK toggle.
